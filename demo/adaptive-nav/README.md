# Adaptive Navigation Demo

Demonstrates replace and stack presentation from the same route tree, with routes discovered from `src/routes`, loaded through the compiler, rendered from route modules that import `vanjs-core` directly, and guided by route-level `navigation.ts` policy for transition, swipe-back, and retention behavior.

For the quickest evaluator flow, start with `bun run start` and `demo/showcase`. This folder stays as the focused reference for adaptive presentation behavior, separate from the six-mode showcase gallery.
